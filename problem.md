# Even or Odd Algorithm

1. Ask the user to enter a number.
2. Store the number entered by the user.
3. Divide the number by 2.
4. Find the remainder of that division.
5. Check if the remainder is equal to 0.
6. If the remainder is 0, the number is even.
7. If the remainder is not 0, the number is odd.
8. Display the result (even or odd) to the user.
